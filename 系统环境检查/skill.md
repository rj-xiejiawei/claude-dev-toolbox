# 系统环境检查

快速检查当前开发环境的所有工具状态和配置。

## 用法

```
/系统环境检查
```

## 检查内容

- 系统基础 (OS, Shell, Docker)
- 版本管理器 (nvm, SDKMAN)
- Claude生态 (CLI, 插件, skills)
- 开发语言 (Node, Java, Go, Python)
- Shell增强 (Oh My Zsh, fzf, 插件)
- 配置文件完整性
